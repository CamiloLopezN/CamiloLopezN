# Sistema de Marca (`sistema-de-marca.md`) — ADN Visual Reutilizable

> **Diferencia clave con `CLAUDE.md`:**
> - **`CLAUDE.md`** define las **leyes físicas y técnicas del motor** (`window.seek(t)`, resortes en forma cerrada, bucle de crítica con `contact.png`, mezcla a `-14 LUFS`).
> - **`sistema-de-marca.md`** conserva el **ADN visual de tu marca o cliente** (logo oficial, colores exactos en hexadecimal, tipografías, sombras y capturas verificadas con Playwright) para que el video 1, el 10 y el 20 mantengan la misma identidad visual sin reinventar fuentes ni colores.

## 2. Paleta Cromática Oficial (Hex)
| Rol | Hex | Uso |
|---|---|---|
| **Fondo Claro (`Paper`)** | `#FFFFFF` / `#F7F6F3` | Actos de producto, ensamblaje de interfaz y cierre |
| **Fondo Invertido (`Dark Invert`)** | `#111111` | Golpe dramático del Acto 1 (*«Ninguna respuesta.»*) y Acto 4 (*«100M usuarios»*) |
| **Tinta Principal (`Ink`)** | `#111111` | Titulares cinéticos y encabezados |
| **Tinta Secundaria (`Muted`)** | `#787774` | Metadatos, migas de pan y etiquetas |
| **Acento Primario (`Brand Accent`)** | `#2383E2` | Botones primarios, foco del cursor, agente activo |
| **Bordes de Interfaz (`Border`)** | `#E5E4DF` | Contorno de tarjetas recortadas (`1.5px` sólido) |

## 3. Tipografía y Reglas de Composición
- **Display / Gancho Cinético:** `Inter` `800`, `-0.035em` tracking, `104px–124px`.
- **UI / Componentes Reales:** `Inter` `500` y `600`. Prohibido redibujar menús desde la imaginación; siempre recortar y animar sobre las capturas reales de `assets/`.
- **Métrica Verificada (Acto 4):** `100 millones de usuarios en más de 50 países` (prohibido inventar cifras no publicadas en el sitio).
